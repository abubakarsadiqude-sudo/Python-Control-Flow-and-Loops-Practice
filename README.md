# Python Programming Practice – Control Flow & Loops

## 📌 About This Repository

This repository contains 11 Python programming exercises designed to strengthen fundamental programming concepts through practical problem-solving.

These exercises focus on conditional statements, loops, nested loops, mathematical operations, number patterns, and logical problem-solving.

The goal is to improve Python programming skills by solving problems independently and developing strong programming fundamentals.

## 🎯 Topics Covered

- Conditional Statements (if, elif, else)
- For Loops
- While Loops
- Nested Loops
- Break Statement
- Mathematical Operations
- Prime Numbers
- Fibonacci Series
- Star and Number Patterns
- GCD and LCM
- Armstrong Numbers
- Logical Problem Solving

## 📝 Practice Exercises

| # | Exercise | Description |
|---|---|---|
| 01 | Triangle Validation | Check whether three sides form a valid triangle and classify it. |
| 02 | Menu-Driven Program | Check even/odd, calculate square, cube, or exit. |
| 03 | Prime Numbers | Print all prime numbers between 2 and N. |
| 04 | Prime Number Checker | Check whether a number is prime using optimized divisor checking. |
| 05 | Fibonacci Series | Generate Fibonacci sequence up to N terms. |
| 06 | Right-Angled Star Pattern | Print a right-angled triangle using stars. |
| 07 | Pyramid Pattern | Print a centered pyramid of stars. |
| 08 | Number Pattern | Print an increasing number pattern using nested loops. |
| 09 | GCD Calculator | Find the greatest common divisor of two positive integers. |
| 10 | LCM Calculator | Find the least common multiple without external libraries. |
| 11 | Armstrong Number | Check Armstrong numbers with any number of digits. |
